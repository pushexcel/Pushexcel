Data Table (What-If Analysis)

Data Table menghitung satu rumus berulang kali dengan nilai masukan berbeda, misalnya cicilan pada berbagai suku bunga.

Langkah praktik

  1. Susun rumus di sudut kiri atas tabel, nilai masukan di kolom (atau baris) di sampingnya.
  2. Blok seluruh tabel.
  3. Data > What-If Analysis > Data Table.
  4. Isi Column input cell dengan sel masukan yang dipakai rumus (atau Row input cell untuk deret baris).
  5. Tekan OK.

Tangkapan layar praktik

Coba interaktif dan kerjakan kuis
