Mengenal editor VBA

Editor VBA (Alt+F11) adalah tempat menulis, membaca, dan mengubah kode macro.

Sub NamaMacro()
    ' kode di sini
End Sub

Langkah praktik

  1. Tekan Alt+F11 untuk membuka editor.
  2. Pilih Insert > Module untuk membuat modul kosong.
  3. Tulis kode di antara Sub dan End Sub.
  4. Tekan F5 untuk menjalankan, atau jalankan dari Developer > Macros.
  5. Contoh: Range("A1").Value = "Halo" mengisi sel A1.

Tips

Komentar diawali tanda apostrof ' dan diabaikan saat dijalankan.
