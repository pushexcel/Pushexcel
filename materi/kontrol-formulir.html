Combo Box dan Option Button

Kontrol formulir memudahkan pengisi memilih nilai dari daftar atau opsi, lalu hasilnya dipakai oleh rumus.

Langkah praktik

  1. Aktifkan tab Developer (File > Options > Customize Ribbon).
  2. Developer > Insert > Combo Box (Form Controls), lalu gambar di lembar kerja.
  3. Klik kanan > Format Control: isi Input range (daftar pilihan) dan Cell link (sel penampung nomor pilihan).
  4. Pakai =INDEX(daftar; sel_link) untuk menampilkan pilihan yang dipilih.
  5. Option Button bekerja sama: setiap tombol mengisi Cell link dengan angka urutannya.

Tangkapan layar praktik

Coba interaktif dan kerjakan kuis
