Menghubungkan data antar sheet dan antar file

Rumus bisa mengambil nilai dari sheet atau file lain. Hasilnya ikut berubah saat data sumber berubah.

Di halaman ini:Langkah praktikTipsTangkapan layar praktik (9)Materi terkait

Coba langsung di browserLembar kerja mini, kuis, dan tanda selesai.

Buka versi interaktif
=Sheet2!B5   atau   ='[Data.xlsx]Sheet1'!$B$5

Langkah praktik

  1. Buka kedua file. Gunakan View > View Side by Side agar keduanya tampil bersamaan.
  2. Di file tujuan ketik =, lalu pindah ke file sumber dan klik sel yang diambil.
  3. Tekan Enter. Excel menuliskan alamat lengkapnya.
  4. Bila file sumber dipindah, gunakan Data > Edit Links untuk memperbaiki hubungan.

Tips

Jangan ganti nama atau pindahkan file sumber tanpa memperbarui link.

Tangkapan layar praktik

9 gambar langkah demi langkah. Klik gambar untuk membuka ukuran penuh.

Materi lain di Dasar Excel

  • Freeze Panes: mengunci baris dan kolom
  • Memindahkan dan menyalin sheet ke file lain
  • Mengatur halaman cetak dan judul berulang
  • Combo Box dan Option Button
  • Mengatur jumlah desimal
  • Menampilkan angka nol di depan
