Mengenal tombol-tombol di Ribbon

Mengenal tab Home, Formulas, dan Data di Ribbon beserta tombol yang paling sering dipakai.

Langkah praktik

  1. Perhatikan tab Home: kelompok Font, Alignment, dan Number berisi pengaturan tampilan.
  2. Tab Formulas berisi pustaka fungsi dan tombol AutoSum.
  3. Tab Data berisi urutkan, filter, dan validasi.
  4. Arahkan kursor ke tombol untuk melihat keterangan singkatnya.
