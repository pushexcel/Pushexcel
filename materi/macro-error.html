Mengatasi macro yang error

Pesan seperti 'Macros have been disabled' atau galat saat dijalankan biasanya disebabkan pengaturan keamanan atau kode yang salah.

Di halaman ini:Langkah praktikTipsTangkapan layar praktik (5)Materi terkait

Coba langsung di browserLembar kerja mini, kuis, dan tanda selesai.

Buka versi interaktif

Langkah praktik

  1. Buka File > Options > Trust Center > Trust Center Settings > Macro Settings.
  2. Pilih Disable all macros with notification agar muncul pilihan Enable Content saat file dibuka.
  3. Untuk galat dalam kode, klik Debug; baris bermasalah akan disorot kuning.
  4. Perbaiki baris tersebut lalu tekan F5 untuk melanjutkan atau tombol Reset untuk berhenti.

Tips

Hanya aktifkan macro dari file yang kamu percayai.

Tangkapan layar praktik

5 gambar langkah demi langkah. Klik gambar untuk membuka ukuran penuh.
