PivotTable: meringkas data besar

PivotTable meringkas ribuan baris menjadi tabel ringkasan hanya dengan menyeret kolom.

Langkah praktik

  1. Klik sel di dalam data (data harus punya judul kolom).
  2. Insert > PivotTable > OK.
  3. Seret kolom kategori ke Rows, kolom angka ke Values.
  4. Klik kanan angka di Values > Value Field Settings untuk mengganti Sum menjadi Count atau Average.
  5. Setelah data berubah, klik kanan > Refresh.
