Membuat kode barcode di Excel

Barcode dibuat dengan menginstal font barcode lalu mengubah format teks kode menjadi font tersebut.

Langkah praktik

  1. Instal font barcode (misalnya Code 39) di komputer.
  2. Ketik kode di sel, untuk Code 39 awali dan akhiri dengan tanda bintang: *12345*.
  3. Ubah font sel menjadi font barcode.
  4. Perbesar ukuran huruf agar mudah dipindai.

Tangkapan layar praktik

Coba interaktif dan kerjakan kuis
