Latihan Excel untuk administrasi perkantoran

24 paket soal dari pekerjaan admin sehari-hari: absensi, stok, kas, gaji, surat, SPP, faktur, aset, kendaraan, data kontak, pengadaan, komisi sales, PPDB, umur piutang, lembur, penginapan, cicilan, sampai laporan laba rugi. Total 295 soal, semuanya bisa diunduh sebagai file Excel atau CSV.

  1. Unduh file soal Excel (atau data CSV) dari paket yang kamu pilih.
  2. Kerjakan dengan rumus pada sel berwarna kuning, ikuti nomor soal.
  3. Cocokkan jawabanmu dengan kunci di halaman paket atau di file kunci.

Tingkat Pemula 6 paket

Rumus dasar: SUM, IF, COUNTIF, dan perhitungan sederhana.

Catatan

  • Semua nama, perusahaan, dan angka dalam latihan ini fiktif dan dibuat untuk belajar.
  • Rumus ditulis dengan titik koma (;) seperti Excel berbahasa Indonesia. Bila Excel kamu berbahasa Inggris, pakai koma (,).
  • File CSV memakai pemisah koma dan sandi UTF-8. Bila data menumpuk di satu kolom, pakai Data > From Text/CSV.
